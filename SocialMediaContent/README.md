# SocialMediaContent

Marketing and publishing assets for **Audio Stegano** (صوت‌نهان).

| Subfolder | Contents |
|-----------|----------|
| [`wordpress/`](wordpress/) | WordPress posts (fa/en), WebP images |
| [`gemini/`](gemini/) | Gemini Create Video prompts (`fa/` Persian, `en/` English) |

## Quick commands

```powershell
# Regenerate WebP images (fa + en)
python SocialMediaContent/wordpress/scripts/convert-screenshots-to-webp.py

# Persian promo
# SocialMediaContent/gemini/fa/gemini-create-video-promo.json

# English promo
# SocialMediaContent/gemini/en/gemini-create-video-promo.json
```
